Where your meetings are kept

Picks, 27 Oct 2026: 1B 2C 3C 4B. A path bar, Home › SigmaFlow › Meetings; a click on a part shows that folder selected in the one around it (Meetings: the SigmaFlow folder opens with Meetings selected); the path stays while deleting and just after.

Asked 27 Oct 2026: show people where their meetings live, on this Mac, and let one click open that folder in Finder. The footer strip that holds Delete meetings has room on its left. The same goes for Conversations. Meeting names below are made up.

From Mobbin: very few apps show where files live on disk, so most of these ideas come from the Mac itself. The closest pattern is the path bar along the bottom of a file list, as in Google Drive (My Drive › Feedback form) and in Finder’s own path bar. Settings › Your data already shows the folder as a boxed path that opens Finder. Option C reuses that button.

Hover the footers. Each one shows how it looks before and after the pointer is on it.

1. The footer

1AThe path, as faint as Delete

A folder icon and ~/SigmaFlow/Meetings in mono on the left, matching Delete meetings on the right. Hover brightens it and underlines the path. The strip stays quiet, just as the delete link is quiet.

1BA path bar, like Finder’s

SigmaFlow › Meetings, each part with its own folder icon. Clicking a part opens that folder: Meetings opens the meetings, and SigmaFlow opens the whole folder, which also holds Conversations and Dictations.

1CThe Settings button, moved here

The same boxed path button as Settings › Your data, at full ink. It is easy to find, and it looks like the button on Settings. Delete stays faint, so the two never look alike.

1DOne plain sentence

“Kept on this Mac in ~/SigmaFlow/Meetings”, with the path as the link. This one does the most to build trust. It also breaks the rule against reassurance lines (13 Oct). Pick it only if building trust is worth that one exception.

1EThe path, and Open in Finder on hover

Like 1A, but the path says nothing about what a click does until the pointer is on it. Then “Open in Finder” appears beside it.

2. A click opens

2AThe Meetings folder

Finder opens ~/SigmaFlow/Meetings, with the year folders inside. Conversations opens ~/SigmaFlow/Conversations.

2BThis month’s folder

Finder opens Meetings/2026/10 October, where the newest meetings are. It is one step closer to the files, but the path on screen gets longer every month.

2CThe SigmaFlow folder, Meetings selected

Finder opens ~/SigmaFlow with Meetings highlighted. People can see that Conversations and Dictations sit right beside it.

3. How the path reads

3A~/SigmaFlow/Meetings

Short, and the way Settings already writes it. The ~ means the home folder. Some people won’t know that.

3B/Users/alex/SigmaFlow/Meetings

The full path, with nothing to decode. It is longer, and it shows the Mac’s account name on a page people may share on screen.

3CHome › SigmaFlow › Meetings

Words, not slashes, like Finder’s path bar. Goes with 1B.
