Switch 06, the icon

A puts an arrow after the words, because the button takes you into the meeting. B is an eye. C is a page, a file icon that the sidebar never uses.

Four ways to show a searched word

A: a soft grey patch behind the word. B: the word is underlined. C: a thin outline around the word. D: the word is underlined and the lines without it fade back, so your eye lands only where it matters. None of them uses bright white.

The buttons

Play 48 min plays the recording. Copy (.md) puts the whole transcript on the clipboard as Markdown. Download (.md) shows the saved file in Finder. Copy and Download are always the same width.

Where it sits

SigmaFlow is in your home folder, next to Documents, so nothing syncs unless you move it into a synced folder yourself.

This is what Download (.md) shows: the file, selected

Two columns

Time in square brackets on the left, what was said on the right. The top is labelled lines.

How the table looks depends on the app

Apps that read Markdown (Obsidian, Bear, Typora, the transcript inside SigmaFlow) draw a real table. A plain text editor shows the raw file, with the columns marked by | lines.

One place for the folder

The path with the folder icon opens it in Finder. Change is for when you have moved it.

Why Export exists, and when it can go

Export copies your dictionary, snippets, styles, settings and dictation history into a "SigmaFlow Export" folder on your Desktop, because today those live in a hidden folder. Switch 04 B is the tab once they move into the SigmaFlow folder too.
