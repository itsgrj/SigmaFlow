Dropping a recording on Meetings

Picks, 28 Oct 2026: 05 15 16 17 19. 05 with Gokul's changes: the button reads "Upload meeting" and carries an upload icon, not a plus.

Asked 28 Oct 2026: any audio or video file dropped on the Meetings page becomes a meeting, but nothing on the page says so once the list has a meeting in it. The only hint is the empty state's "Press Record meeting, or drop a recording here." These are 20 ways to let people know, each drawn on its own. They can be combined. Meeting names are made up.

Reply with the numbers you want, for example "01 05 13". Where two would fight for the same spot (05 and 06 both change the button), pick one of them.

From Mobbin: every transcription app shows import as plainly as Record. Otter puts Import beside Record. Fireflies and Grain put a drop area above the list. Mistral writes "or drag and drop files here" under its buttons and offers Paste with ⌘V. Savee covers the whole window while a file is held over it. None of them hides it the way SigmaFlow does now.

    A. Words in places the page already has

    01The subtitle says it

    "Record a meeting, or drop in a recording, and read it back the moment it ends." Nothing new is added to the page, and the line is read on every visit. Mobbin: Mistral.

    02The line under the button says it

    "Press ⌃⌥M, or drop a file here." It uses the line that already sits under Record meeting, right where the eye goes for "how do I add one".

    03A faint line in the footer

    "Drop a recording here to transcribe it", in the middle of the footer, as faint as the folder path and Delete meetings. It stays in view however far the list scrolls.

    04A tooltip on Record meeting

    The ordinary Mac tooltip after the pointer rests on the button: "Or drop an audio or video file on this page." It costs nothing, but only people who hover ever see it.

    B. A real button, so dropping is not the only way in

    05Add a recording, beside Record meeting

    A second, quieter button. It opens the Mac's file picker and runs exactly what a drop runs. Mobbin: Otter (Import beside Record).

    06A split button

    Record meeting keeps its place; the small arrow beside it opens a menu with Add a recording. The header looks almost the same until the arrow is clicked. Mobbin: Substack.

    07File › Add Recording… ⌘O

    In the Mac's menu bar, next to Record Meeting and Take Notes. Mac people look in the menus for what an app can do, and ⌘O works from any page.

    08Paste a file with ⌘V

    Copy a recording in Finder, press ⌘V on Meetings, and it is added. Edit › Paste names it while a recording is on the clipboard, which is how people find it. Mobbin: Mistral (Paste files ⌘V).

    C. A place in the list where recordings land

    09A dashed row at the top of the list

    Always there, above this month: "Drop a recording here, or choose one". Clicking "choose one" opens the file picker. The plainest of all, and it costs one row of the list. Mobbin: Fireflies, Grain.

    10A faint row at the end of the list

    After the oldest meeting, where the list runs out. Shown here scrolled to the bottom. It never pushes a meeting down.

    11Add in the month heading

    A faint "+ Add a recording" at the right of OCTOBER 2026. Only the newest month carries it.

    12The dropped file shows straight away, with a note in the corner

    The row already appears as Transcribing. The corner note, "Transcribing Weekly sync.mp4", makes the very first drop unmistakable, so people trust it and do it again. Mobbin: Grain ("Uploading 1 recording").

    D. Make the target obvious once a drag starts

    13Drop on any page

    A recording held over the window on any page brings up the veil: "Drop to add to Meetings". Today only the Meetings page takes it; try it on Transcriptions and nothing happens, and people decide it doesn't work. After the drop, the app moves to Meetings with the new row on top. Mobbin: Savee.

    14The sidebar's Meetings takes drops

    From any page, hold the file over Meetings in the sidebar; it gets a white edge and "Drop". Smaller than 13, and it teaches where the recording will go.

    15The veil names the file

    The veil the app already draws, with the file's name and length under "Drop to transcribe", so you know it was understood before you let go.

    E. Outside the window

    16Drop on the Dock icon

    A recording dropped on SigmaFlow in the Dock becomes a meeting, without opening the page first. Declaring the file types also adds SigmaFlow to Finder's Open With menu.

    17A Finder Quick Action

    Right-click a recording in Finder, Quick Actions, Transcribe with SigmaFlow. Found where people already are when they have a file in hand.

    18A folder that takes recordings

    ~/SigmaFlow/Meetings/Add to SigmaFlow: anything put in it is transcribed and filed as a meeting, then leaves that folder. It fits "the folder is the record", and the folder's name says what it does.

    F. Teach it once

    19One onboarding step

    After the folder step: Meetings, two ways, side by side, with a real drop target on the right. Onboarding is the one place a step may carry a line under its title.

    20A one-time card after the first meeting

    Shown once, the first time a recorded meeting is filed: "You can also drop a recording here." with Got it. This breaks the rule against how-it-works lines (13 Oct), so it is here to make the set complete.
