What it does

Push to talk

Right ⌥, Right ⌘ or your own shortcut. Double tap for hands-free. Esc throws it away.

A dictionary that learns

Fix a misheard word in any app and SigmaFlow offers the rule. One click undoes it.

Five speech engines

Apple SpeechAnalyzer by default, or Parakeet, Nemotron and Cohere models, all on device.

Styles

Select text, press ⌥1 to ⌥5, get it rewritten in a voice you trained on your own writing.

Meetings and live notes

Record a call or a room, get a transcript with speakers. Tamil and English both work.

Talks to Claude

A bundled MCP server lets Claude Desktop search your dictations and meetings locally.

Install

  1. Download SigmaFlow.dmg from the latest release.
  2. Drag it to Applications. It is signed but not notarized yet, so the first launch needs Open Anyway in System Settings ▸ Privacy & Security.
  3. Grant Accessibility and Microphone, then hold Right ⌥ and talk.

Build from source

git clone https://github.com/itsgrj/SigmaFlow
cd SigmaFlow
make install   # build, sign, copy to /Applications, launch

How it works

In the real README this is a Mermaid diagram, which GitHub draws natively and anyone can edit as text.

The full architecture, the invariants and why they exist are in CLAUDE.md. The list of things that look like bugs and are not is in AGENTS.md.

Privacy

Speech, cleanup, the dictionary and meetings all run on your Mac. Nothing leaves it unless you choose a cloud style backend and paste in your own API key, which stays in the Keychain.

How this was built

I am a product marketer, not a Swift developer. I designed SigmaFlow and wrote every spec; the code was written with Claude Code, which is why most commits carry a Claude co-author line. Every feature started as an interactive mockup (20 of them are in docs/mockups) and shipped only once the design was agreed.

Not built yet

  • Onboarding: a first-run window for both permissions
  • Notarization, so there is no Open Anyway step

SigmaFlow

macOSpassing platformmacOS 26 Swift6.2 licenseMIT releasev0.6

Native push-to-talk dictation and meeting transcription for macOS. Swift 6, SwiftUI, no Electron, no server. All speech runs on the Mac.

By the numbers

WhatMeasured on my MacBook Pro
115 minute meeting, transcribed and split by speakerabout 100 s, 1 GB peak
12 minute Tamil and English meeting38 s in a release build

Codebase18,773 lines of Swift in 77 files
Correction contract36 test vectors, run by CI on every push

Architecture

Invariants that fail silently if broken

RuleWhat goes wrong without it
One audio stream, drained by one taskBuffers arrive out of order and the transcript reads as word salad
runGeneration is checked by every async tailA cancelled run pastes over the run that replaced it
The dictionary runs last, alwaysA style pass lowercases names the dictionary just fixed
The overlay can never become keyThe target field loses focus and nothing gets typed
A second press during finishing is refusedThe same sentence is pasted twice
